## 🚀 Featured Projects

### 💊 [evapharm](https://github.com/TheQuietBeatle/evapharm) — WhatsApp automation for a real pharmacy
An n8n pipeline that handles customer messages over WhatsApp using the **Meta Cloud API** with **Groq / Anthropic** LLMs, running in **Docker** and deployed at my family's pharmacy. The companion React app is deployed on **Vercel**.

`n8n` `Docker` `Meta Cloud API` `Groq` `Anthropic API` `React` `Vercel`

### 🧩 Power-Puff — Talent Marketplace SPA
A React single-page app built for GUC's Talent Marketplace: **28+ routes**, role-gated routing, Kanban boards, and analytics dashboards. Started as a CSEN603 course project and grew from there.

`React 19` `Vite` `MUI` `Framer Motion`

### 📬 AI Email Triage Pipeline
Monitors a Gmail inbox, classifies incoming mail with **Llama 3.3 70B on Groq**, and pushes the important stuff to **Telegram**.

`n8n` `Gmail API` `OAuth2` `Groq` `Telegram Bot API`

### 🏠 Smart Home Dashboard *(in progress)*
A React dashboard for a 7" wall tablet, bridging to **Home Assistant** with a swipeable widget-grid layout.

`React` `Home Assistant`

### 🧸 NurseryLink — OGTech Internship 2026
Team project: a nursery management platform for admins, teachers, and parents — class & student management, meal / temperature logs with fever alerts, and parent notifications. I also designed an offline-first sync module (IndexedDB outbox, exponential backoff, captive-portal detection).

`ASP.NET Core` `EF Core` `SQL Server` `JavaScript`
